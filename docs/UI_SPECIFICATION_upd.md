## 1. Общие принципы

### 1.1 Два режима работы (Dual Mode)

| Режим | Описание | Иконка | Приоритет |
|-------|----------|--------|-----------|
| **FREE_FORM** | Свободное редактирование текста (Word-like) | 📄 | Равный |
| **STRUCTURED_FORM** | Формы с полями и валидацией | 📋 | Равный |

Переключение режимов — через меню или автоматически по типу документа.

### 1.2 WYSIWYG + WYSIWYP

- **WYSIWYG**: В редакторе видим текст как он будет выглядеть при печати
- **WYSIWYP**: What You See Is What You Print — форматирование соответствует ESC/P выводу

### 1.3 Responsive Layout

- StatusBar становится **двухстрочным** при недостаточной ширине окна (< 800px)
- Боковая панель сворачивается в иконки при узкой ширине

## 3. MainWindow — Главное окно

### 3.1 Расположение компонентов

| Компонент | Расположение | Переключаемость |
|-----------|--------------|-----------------|
| MainToolbar | Сверху | Нет |
| SideBar | Слева | Да (Ctrl+B) |
| FormatToolbar | Под MainToolbar | Нет (динамически для режима) |
| CardFileTabBar | Под FormatToolbar | Нет |
| DocumentView | Центр | Нет |
| StatusBar | Снизу | Нет |

### 3.2 Layout Grid

```python
# Grid layout для MainWindow
# row 0: MainToolbar (columnspan=2)
# row 1: SideBar | FormatToolbar (columnspan)
# row 2: SideBar | CardFileTabBar (columnspan)
# row 3: SideBar | DocumentArea (Ruler + Text + Navigator)
# row 4: StatusBar (columnspan=2, может быть 2 строки)
```

### 3.3 Управление видимостью

- **SideBar**: Кнопка в MainToolbar + Ctrl+B
- **FormatToolbar**: Всегда видна, но содержимое меняется по режиму
  - FREE_FORM: Полное форматирование текста
  - STRUCTURED_FORM: Минимальное + индикаторы полей

- Текущее состояние: ● (заполненный круг)
- Пройденные: ✓
- Будущие: ○ (пустой круг)

### 9.1 Индикаторы в StatusBar

- **Progress Bar**: Визуальное отображение состояний
- **Role Badge**: Цветной индикатор текущей роли

  - EDITOR: 🟢 Зелёный
