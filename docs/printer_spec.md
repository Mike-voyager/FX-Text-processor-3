# Epson FX-890: Техническая спецификация ESC/P

> Документ содержит полную техническую спецификацию принтера Epson FX-890 и справочник команд ESC/P для использования в FX Text Processor 3.
>
> **Источники:** [Epson FX-890 Reference Guide](https://files.support.epson.com/htmldocs/fx890_/fx890_rf/apspe_2.htm), [Command Lists](https://files.support.epson.com/htmldocs/fx890_/fx890_rf/apspe_3.htm)

---

## 1. Механические характеристики

### Метод печати
- **Тип:** 9-игольчатый ударный матричный принтер (impact dot matrix)
- **Конфигурация:** 9 игл (wire pins), расположены вертикально в один столбец
- **Диаметр точки:** ~0.3 мм
- **Максимальное разрешение:** 240 × 144 dpi (NLQ-режим)

### Скорости печати по режимам

| Режим | 10 cpi | 12 cpi |
|-------|--------|--------|
| Ultra High Speed Draft | 566 cps | 680 cps |
| High Speed Draft | 559 cps | 627 cps |
| Draft | 419 cps | 503 cps |
| Draft Emphasized | 209 cps | — |
| Near Letter Quality (NLQ) | 104 cps | 125 cps |

### Ключевые механические параметры

| Параметр | Значение |
|----------|----------|
| Направление печати | Двунаправленное с логическим поиском (bidirectional logic seeking) |
| Межстрочный интервал | 1/6 дюйма по умолчанию, программируемо шагом 1/216 дюйма |
| Скорость подачи бумаги (непрерывная) | 127 мм/сек |
| Скорость подачи (межстрочная) | 46 мс/строку при шаге 1/6 дюйма |
| Ресурс головки | 400 млн ударов/игла; ~400 млн символов Draft 10 cpi |
| Общий ресурс принтера | 52 млн строк; MTBF 20 000 POH |

### Нюансы 9-игольчатой печати

- **Разрешение по вертикали:**
  - Draft: 72 dpi (9 игл × 1 проход)
  - NLQ: 144 dpi (два прохода со смещением на полшага)

- **Разрешение по горизонтали:**
  - Обычная Draft-печать: 120 или 60 dpi
  - Максимум 240 dpi: режим `ESC * m` с m=3

- **Bidirectional logic seeking:** принтер самостоятельно выбирает направление каретки и пропускает пустые зоны. Может давать небольшое горизонтальное несовпадение точек (~0.1–0.2 мм) в режиме двунаправленной графики — для точной графики использовать `ESC U 1` (однонаправленная печать).

- **Лента:** картридж S015329; ресурс ~7.5 млн символов (Draft, 10 cpi)

## 2. Электронные характеристики

| Параметр | Значение |
|----------|----------|
| **Буфер** | **128 KB** |
| Интерфейсы | Параллельный IEEE 1284 (8-bit, bidirectional, nibble mode); USB 1.1; слот для опционального интерфейса Type B |
| Эмуляции | ESC/P (основная), IBM PPDS (Proprinter) |

> **Важно:** Буфер 128 KB — весь приём данных от хоста. При передаче через USB/параллельный порт данные копятся в буфере, принтер обрабатывает их независимо. Необходимо контролировать flow control (XON/XOFF или hardware handshake через IEEE 1284).

## 3. Шрифты и символьные таблицы

### Встроенные bitmap-шрифты

| Шрифт | Поддерживаемые pitch |
|-------|---------------------|
| EPSON Draft | 10, 12, 15 cpi |
| EPSON Roman | 10, 12, 15 cpi, proportional |
| EPSON Sans Serif | 10, 12, 15 cpi, proportional |

**NLQ-шрифты** (Roman, Sans Serif) доступны только в режиме `ESC x 1`. В Draft (`ESC x 0`) всегда печатается Draft-шрифт.

### Выбор шрифта: ESC k n

| n | Шрифт |
|---|-------|
| 0 | Roman |
| 1 | Sans Serif |

### Символьные таблицы (Character Tables)

**Стандартная конфигурация:** 1 Italic + 12 графических таблиц
**Расширенная конфигурация:** 1 Italic + 38 графических таблиц

Выбор таблицы: `ESC t n`

| n | Таблица |
|---|---------|
| 0 | Italic table |
| 1 | PC437 (IBM USA, стандартная) |
| 2 | PC850 (Multilingual) |
| 3 | PC860 (Portuguese) |
| 4 | PC863 (French Canadian) |
| 5 | PC865 (Nordic) |
| ... | ... (до 38 таблиц в расширенной конфигурации) |

### Международные наборы символов: ESC R n

13 наборов: USA (0), France (1), Germany (2), UK (3), Denmark I (4), Sweden (5), Italy (6), Spain I (7), Japan (8), Norway (9), Denmark II (10), Spain II (11), Latin America (12).

Команда `ESC R n` меняет только специальные символы в диапазоне ASCII 0x23–0x7E.

## 4. Справочник ESC/P-команд

### 4.1 Общие операции

| Команда | Байты | Функция |
|---------|-------|---------|
| `ESC @` | 1B 40 | Сброс принтера в исходное состояние (initialize) |
| `ESC U n` | 1B 55 n | Однонаправленная (n=1) / двунаправленная (n=0) печать |
| `ESC EM n` | 1B 19 n | Управление бумагой (n=1: cut sheet eject; n=2: tear-off) |

> **Важно:** `ESC @` сбрасывает **все** настройки: шрифт, pitch, межстрочный интервал, таблицы символов, пользовательские символы.

### 4.2 Подача бумаги

| Команда | Байты | Функция |
|---------|-------|---------|
| `FF` | 0C | Прогон до начала следующей страницы (form feed) |
| `LF` | 0A | Перевод строки на текущий межстрочный интервал |
| `CR` | 0D | Возврат каретки |
| `ESC 0` | 1B 30 | Межстрочный интервал 1/8 дюйма |
| `ESC 2` | 1B 32 | Межстрочный интервал 1/6 дюйма (по умолчанию) |
| `ESC 3 n` | 1B 33 n | Межстрочный интервал n/216 дюйма (n: 0–255) |
| `ESC 1` | 1B 31 | Межстрочный интервал 7/72 дюйма |
| `ESC A n` | 1B 41 n | Межстрочный интервал n/72 дюйма (n: 1–85) |
| `ESC J n` | 1B 4A n | Однократный прогон на n/216 дюйма вперёд без LF |

**Нюансы:**
- `ESC A` задаёт шаг в единицах 1/72", но применяется только после `ESC 2`
- `ESC 3` — наиболее точная команда: шаг 1/216 дюйма (~0.118 мм)
- `ESC J` — разовый сдвиг, после которого принтер возвращается к текущему интервалу

### 4.3 Формат страницы

| Команда | Байты | Функция |
|---------|-------|---------|
| `ESC C n` | 1B 43 n | Длина страницы в строках (n: 1–127) |
| `ESC C 0 n` | 1B 43 00 n | Длина страницы в дюймах (n: 1–22) |
| `ESC (C n1 n2 l1 l2` | 1B 28 43 ... | Длина страницы в единицах 1/360 дюйма (16-бит) |
| `ESC Q n` | 1B 51 n | Правый край (right margin) в символах от левого края |
| `ESC l n` | 1B 6C n | Левый край (left margin) в символах |
| `ESC N n` | 1B 4E n | Установка отступа skip-over-perforation (n строк) |
| `ESC O` | 1B 4F | Отключение skip-over-perforation |
| `ESC (c n1 n2 t1 t2 b1 b2` | | Верхнее/нижнее поля в единицах 1/360 дюйма |
| `ESC (U n1 n2 d` | 1B 28 55 01 00 d | Единица измерения (d=60: 1/60", d=120: 1/120", d=180: 1/180") |

**Ограничения полей:**
- Физический минимальный верхний/нижний отступ: **4.2 мм** от края бумаги
- Минимальный левый и правый отступ: **3 мм**
- Максимальная печатная ширина: **203.2 мм (8 дюймов)**

### 4.4 Движение каретки

| Команда | Байты | Функция |
|---------|-------|---------|
| `ESC $ n1 n2` | 1B 24 n1 n2 | Абсолютная горизонтальная позиция: (n1 + n2×256) × 1/60" |
| `ESC \ n1 n2` | 1B 5C n1 n2 | Относительное горизонтальное смещение (знаковое, ±) |
| `HT` | 09 | Горизонтальная табуляция к следующей позиции |
| `ESC D n ... NUL` | 1B 44 ... 00 | Установить позиции горизонтальных табуляций |
| `VT` | 0B | Вертикальная табуляция к следующей позиции |
| `ESC B n ... NUL` | 1B 42 ... 00 | Установить позиции вертикальных табуляций |

### 4.5 Выбор шрифта

| Команда | Байты | Функция |
|---------|-------|---------|
| `ESC k n` | 1B 6B n | Шрифт: 0=Roman, 1=Sans Serif |
| `ESC x n` | 1B 78 n | Качество: 0=Draft, 1=NLQ |
| `ESC y n` | 1B 79 n | Скорость Draft: 0=обычный, 1=HSD, 2=UHSD |
| `ESC P` | 1B 50 | Pitch 10 cpi (pica) |
| `ESC M` | 1B 4D | Pitch 12 cpi (elite) |
| `ESC g` | 1B 67 | Pitch 15 cpi (semi-condensed) |
| `ESC p n` | 1B 70 n | Пропорциональный шрифт: 1=вкл, 0=выкл |
| `ESC 4` | 1B 34 | Включить курсив (italic) |
| `ESC 5` | 1B 35 | Выключить курсив |
| `ESC E` | 1B 45 | Жирный шрифт (bold) — включить |
| `ESC F` | 1B 46 | Жирный шрифт — выключить |
| `ESC ! n` | 1B 21 n | Мастер-выбор (master select) — битовая маска |

**`ESC ! n` — битовая маска:**

| Бит | Значение при 1 |
|-----|----------------|
| 0 (0x01) | 12 cpi (Elite) |
| 1 (0x02) | Proportional |
| 2 (0x04) | Condensed |
| 3 (0x08) | Bold |
| 4 (0x10) | Double-strike |
| 5 (0x20) | Double-width |
| 6 (0x40) | Italic |
| 7 (0x80) | Underline |

### 4.6 Модификаторы шрифта

| Команда | Байты | Функция |
|---------|-------|---------|
| `ESC W n` | 1B 57 n | Double-width (расширенный): 1=вкл, 0=выкл |
| `SO` / `DC4` | 0E / 14 | Double-width одна строка: вкл / выкл |
| `SI` / `DC2` | 0F / 12 | Condensed (сжатый): вкл / выкл |
| `ESC w n` | 1B 77 n | Double-height (двойная высота): 1=вкл, 0=выкл |
| `ESC G` | 1B 47 | Double-strike (двойной удар) — включить |
| `ESC H` | 1B 48 | Double-strike — выключить |
| `ESC T n` | 1B 54 n | Подстрочный/надстрочный: 0=выкл, 1=superscript, 2=subscript |
| `ESC S n` | 1B 53 n | Подстрочный/надстрочный (алт.): 0=superscript, 1=subscript |
| `ESC - n` | 1B 2D n | Подчёркивание: 1=вкл, 0=выкл |

**Нюансы:**
- **Condensed (SI/DC2):** сжатый режим при 10 cpi даёт 17.1 cpi, при 12 cpi — 20 cpi
- **Double-strike vs Bold:** Double-strike печатает строку дважды с незначительным смещением для насыщенности. Bold — более тёмный built-in bitmap-шрифт

### 4.7 Межсимвольный интервал

| Команда | Байты | Функция |
|---------|-------|---------|
| `ESC Space n` | 1B 20 n | Добавить n/120 дюйма к каждому символьному интервалу (n: 0–127) |

### 4.8 Работа с символами

| Команда | Байты | Функция |
|---------|-------|---------|
| `ESC t n` | 1B 74 n | Выбор кодовой таблицы (character table) |
| `ESC (t n1 n2 ...` | | Расширенный выбор таблицы |
| `ESC R n` | 1B 52 n | Международный набор символов (0–12) |
| `ESC % n` | 1B 25 n | Переключение на пользовательские символы (n=1) / ROM (n=0) |
| `ESC & n1 n2 n3 d1..dk` | 1B 26 ... | Загрузка пользовательских символов в RAM |
| `ESC : 0 n 0` | 1B 3A 00 n 00 | Копирование шрифта из ROM в RAM |
| `ESC 6` | 1B 36 | Разрешить печать символов 128–159 (MSB chars) |
| `ESC 7` | 1B 37 | Запретить печать символов 128–159 |
| `ESC I n` | 1B 49 n | Включить/выключить печать символов 0x00–0x06 и 0x10–0x1F |

### 4.9 Графика (Bit Image)

#### Legacy команды

| Команда | Байты | H разрешение | V разрешение | Описание |
|---------|-------|--------------|--------------|----------|
| `ESC K n1 n2 data` | 1B 4B | 60 dpi | 8 pins | Single density |
| `ESC L n1 n2 data` | 1B 4C | 120 dpi | 8 pins | Double density |
| `ESC Y n1 n2 data` | 1B 59 | 120 dpi | 8 pins | Double density (high speed) |
| `ESC Z n1 n2 data` | 1B 5A | 240 dpi | 8 pins | Quadruple density |
| `ESC ^ n1 n2 data` | 1B 5E | 60/120 dpi | 9 pins | Nine-pin mode |

#### Универсальная команда ESC *

`ESC * m n1 n2 data`
- m — режим (density mode)
- n1 + n2 × 256 = количество столбцов (columns)
- data — по 1 байту на столбец

| m | H разрешение | V разрешение | Соседние точки | Описание |
|---|--------------|--------------|----------------|----------|
| 0 | 60 dpi | 8 pins | Да | Single density |
| 1 | 120 dpi | 8 pins | Да | Double density |
| 2 | 120 dpi | 8 pins | Нет | Double-speed |
| 3 | 240 dpi | 8 pins | Нет | Quadruple density |
| 4 | 80 dpi | 8 pins | Да | CRT I |
| 5 | 72 dpi | 8 pins | Да | Plotter/CRT II |
| 6 | 90 dpi | 8 pins | Да | CRT III |
| 7 | 144 dpi | 8 pins | Да | Triple density |

**Критические нюансы графики для FX-890:**
1. **8 pins:** команды `ESC *` используют только 8 бит данных (иглы 1–8)
2. **Запрет соседних точек:** в режимах m=2, 3 принтер аппаратно подавляет соседние горизонтальные точки
3. **Межстрочный интервал для графики:** перед блоком устанавливать `ESC 3 n` с n=24 (1/9") или n=36 (для 144 dpi)
4. **Ширина строки:** максимум 480 столбцов при 60 dpi (= 8 дюймов × 60)

### 4.10 Штрихкоды: ESC ( B

`ESC ( B n1 n2 k m s v1 v2 c data`

| Параметр | Значение |
|----------|----------|
| k | Тип: 0=EAN-13, 1=EAN-8, 2=ITF, 3=UPC-A, 4=UPC-E, 5=Code 39, 6=Code 128, 7=POSTNET |
| m | Ширина модуля (180 dpi): 2–5 точек |
| s | Коррекция пробела: от -3 до +3 (1/360 дюйма) |
| v1+v2×256 | Высота штрихкода в 1/180 дюйма |
| c (бит 0) | 0 = принтер добавляет check digit; 1 = не добавляет |
| c (бит 1) | 0 = печатать HRC (читаемые символы); 1 = не печатать |

## 6. Практические рекомендации

### Инициализация документа

```
ESC @              ; сброс
ESC (U 01 00 3C    ; единица = 1/60" (0x3C = 60)
ESC l n            ; левый край
ESC Q n            ; правый край
ESC C n / ESC C 0 n ; длина страницы
ESC 2              ; интервал 1/6" (стандарт)
ESC t 01           ; PC437 или нужная таблица
ESC R 00           ; USA charset
```

### Смена качества печати

```
ESC x 00           ; Draft (быстро)
ESC x 01           ; NLQ (качество)
ESC k 00           ; Roman (для NLQ)
```

### Графическая полоса

```
ESC 3 24           ; 24/216 = 1/9" для 8-pin полосы
ESC * 01 lo hi [data]  ; 120 dpi (m=1)
CR LF              ; переход к следующей полосе
ESC 2              ; восстановить интервал
```

### Расчёт ширины

Максимальная печатная ширина FX-890 = **203.2 мм**:
- 10 cpi: 480 символов
- 12 cpi: 576 символов
- 15 cpi: 720 символов

### Flow Control

- Буфер 128 KB
- Рекомендуется отправлять данные блоками не более 4–8 KB
- Использовать OS-уровневый буфер записи с проверкой errno EAGAIN

## 8. DIP-переключатели

### Ключевые настройки

- **SW1-1:** Auto LF при CR (вкл/выкл)
- **SW1-2:** Пропуск перфорации (skip-over-perforation) 1 дюйм
- **SW1-3/1-4:** Длина страницы по умолчанию
- **SW1-5/1-6:** Выбор символьной таблицы по умолчанию
- **SW1-7:** Международный набор символов по умолчанию
- **SW2-1:** Выбор интерфейса
- **SW2-5/2-6:** Выбор эмуляции (ESC/P / IBM PPDS)

**Рекомендации для fx-text-processor-3:**
- Auto LF **выключен** (SW1-1 = OFF) — управлять LF программно
- Skip-over-perforation выключить, если управление страницей ведётся через `ESC C` / `FF`
