## Чек-лист для разработчиков

### Перед началом работы
- [ ] Прочитать GUI_AUDIT_REPORT.md полностью
- [ ] Изучить CRITICAL проблемы в своем модуле
- [ ] Оценить время на исправление

### В процессе работы
- [ ] Исправлять от CRITICAL к LOW
- [ ] Добавлять тесты на исправленный код
- [ ] Обновлять docstrings
- [ ] Проверять mypy --strict

### Перед коммитом
- [ ] check.sh проходит без ошибок
- [ ] Тесты проходят
- [ ] Coverage не уменьшился
- [ ] Security review пройден (для security кода)

## Контакты и процесс

### Контрольные точки

| Дата | Событие | Критерий успеха |
|------|---------|-----------------|
| Неделя 2 | Демо Phase 1-2 | MFA работает, clipboard работает |
| Неделя 4 | Architecture review | Strategy Pattern реализован |
| Неделя 6 | Quality gate | mypy strict, coverage 90% |
| Неделя 8 | Go/No-go | Все acceptance criteria |

### Definition of Done

1. Код проходит check.sh без предупреждений
2. Тесты проходят с coverage >= 90%
3. mypy --strict без ошибок
4. Security review пройден (для security кода)
5. Документация обновлена
6. Code review пройден
