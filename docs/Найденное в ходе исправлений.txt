4. ПРИМЕРЫ ИСПРАВЛЕНИЙ (ДЛЯ ССЫЛКИ)
================================================================================

До (что было исправлено в src/gui/):
```python
try:
    # alguma operação
    result = risky_operation()
except Exception:
    pass  # или bare except с логированием
```

После (паттерн, использованный в исправлениях):
```python
try:
    # alguma operação
    result = risky_operation()
except (SpecificError1, SpecificError2) as e:
    logger.error(f"Specific error occurred: {e}")
    # соответствующая обработка или повторное поднятие
except UnexpectedError as e:
    logger.exception(f"Unexpected error in operation: {e}")
    # решение о том, повторно ли поднимать или обрабатывать gracefully
```
